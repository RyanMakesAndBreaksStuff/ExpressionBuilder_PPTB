The CLAUDE.md template generated by `sdd-init` should give Claude project context first and guide SDD use selectively based on task size and risk — not trigger `sdd-workflow` before every request.

**Why:** Blanket SDD invocation for trivial tasks (typo fixes, config tweaks, questions) feels like bureaucracy and undermines the workflow's credibility. Claude should use judgment.

**How to apply:** When updating or regenerating the CLAUDE.md template, preserve the "About This Project" placeholder and the "Working in This Project" judgment rule. Hard Gates should be scoped to "when following SDD" not universally.
